# 照片 / 视频 智能分类整理（开源版）

> [!WARNING]
> **⚠️ Windows 离线版是「分卷压缩包」，必须下载全部分卷并合并后才能解压使用！**
>
> 受 GitHub 单文件上传限制，Release 中的 Windows 离线版（约 765MB，已内置 CLIP 模型权重，可断网运行）被拆成 **两个分卷** + 一个合并脚本：
> - `photo-sorter-windows-v1.0.1-offline.z01`
> - `photo-sorter-windows-v1.0.1-offline.z02`
> - `merge_parts.ps1`（合并脚本）
>
> **正确下载步骤**：把上面 **3 个文件全部下载到同一个文件夹** → 右键 `merge_parts.ps1` 选「使用 PowerShell 运行」→ 自动合并出完整的 `照片视频智能分类整理_windows_v1.0.1_offline.zip` → 解压即用（断网可用）。
> **🚫 只下载其中任意一个分卷都无法解压或运行，务必全部下载！**

把一个乱糟糟的照片 / 视频文件夹拖进来，它会看懂每一张图的内容，在**这个文件夹内部**建好类别子文件夹，把文件归位，并按 `类别 + 日期 + 序号` 重新编号。

- **纯本地运行**：识别用的视觉模型装在你自己的电脑上，跑在 CPU，全程离线。
- **零数据外发**：不联网、不上传、不调用任何云端 API，照片只在你电脑内存里被只读分析。
- **硬约束**：绝不重编码、绝不降画质、绝不覆盖、绝不篡改原文件。

## 一、支持平台

| 平台 | 状态 | 启动方式 |
|---|---|---|
| Windows 10/11 | ✅ 已测试 | 双击 `启动.bat` |

## 二、三步开始

### Windows
1. 第一次用，双击 **`安装依赖.bat`**（会装独立 Python 环境 + 视觉模型，约 600MB，全部装在本项目内，不影响你电脑其它 Python）。
2. 双击 **`启动.bat`**。
3. 把照片文件夹拖进窗口 → 点「开始识别（不动文件）」→ 核对 → 点「执行归档」。

### macOS
1. 打开终端，进入本项目目录，赋可执行权限：
   ```bash
   chmod +x 启动.command 安装依赖.command
   ./安装依赖.command
   ```
2. 运行：`./启动.command`

> 提示：macOS 上首次运行 `.command` 若被系统拦截，到「系统设置 → 隐私与安全性」里允许一次即可。

## 三、数据安全与隐私（重要）

本程序是**纯本地桌面工具，没有后端服务器、没有账号、没有云端**。

- 照片 / 视频**只在本机被读取分析**，不会离开你的电脑。
- 运行时**零联网、零上传、零遥测**。唯一的联网动作是「第一次下载视觉模型权重（约 600MB）」，下完之后永久离线，拔掉网线也能用。
- 代码里没有任何 `requests` / 云端 API / 数据上报逻辑（可逐行审计，也欢迎用静态分析工具核查）。
- 开源的固有风险是「恶意改版可能夹带后门上传你的照片」。**请只从我发布的官方 Release 下载**，并核对 SHA256；源码完全公开，任何人可审计。

## 四、编号规则

- 不勾时间板块：`人像/人像01.jpg`、`风景/风景01.jpg`
- 勾时间板块（按年）：`2021-人像/人像01.jpg`
- 手动日期段（填 21）：`人像21-01.jpg`
- 期日编号（自动取照片 EXIF 创建时间）：`人像2021-08-01-01.jpg`

类别名一律取自 `categories.json`（内置或你新增的都用原名）。每个文件夹独立从 01 开始编号，重复整理会续接、不会覆盖已有文件。

## 五、类别清单随便改

点界面右侧「编辑类别清单」，或直接用记事本编辑 `categories.json`：

- **名称** = 文件夹名，也是编号前缀
- **语义描述** = 英文，一行一条，越具体越准
- **特殊规则**：`animated`(动图) / `screenshot`(截图) / `video`(视频单独归类) / 留空(纯语义)

内置类别：动图、截图、证件、人像、风景、博物馆、飞机、宠物、漫画、插画、美食、建筑、车辆、事物，识别不出来的进「其它」。

## 六、四条硬约束（写死在代码里）

| 约束 | 怎么做到的 |
|---|---|
| **绝不重编码** | 只调用文件系统的移动/改名，同盘是原子级，一个字节都不重写 |
| **绝不降画质** | 识别时的缩放全部发生在内存副本，原文件只读打开 |
| **绝不覆盖** | 目标有同名立刻换号；底层 `os.rename` 目标存在会直接报错拒绝 |
| **绝不篡改** | 不写 EXIF、不改扩展名、不改拍摄时间，跨盘复制逐字节校验大小 |

自检脚本会造样本跑完整流程并逐文件比对 MD5，验证上面四条：

```bash
python selftest.py
```

## 七、支持的格式

- 图片：JPG / JPEG / PNG / GIF / WEBP / BMP / TIF / TIFF
- RAW：CR2 / CR3 / NEF / ARW / DNG / ORF / RW2 / RAF / PEF / SRW 等（读相机内嵌预览图）
- 视频：MP4 / MOV / FLV / M4V / AVI / MKV / WMV / WEBM / 3GP（抽 3 帧综合判断）
- HEIC/HEIF 需额外装 `pillow-heif`，否则归到「其它」

## 八、开源协作（GitHub 工作流）

本项目欢迎所有人参与改进。

- **报告问题 / 提建议**：在仓库的 Issues 区描述现象、复现步骤、预期行为。
- **提交修改**：Fork → 改代码 → 跑 `python selftest.py` 确保通过 → 提 Pull Request。
- **接收外部修改**：维护者把 PR 合并进主仓库后，再从主仓库把更新拉回本地继续迭代。
- **版本与发布**：版本号记录在 `VERSION` 文件，变更写进 [CHANGELOG.md](docs/CHANGELOG.md)；每个正式版本打 git tag（如 `v1.0.0`）并发布 Release（含源码包与 Windows exe 的 SHA256）。

贡献规范见 [CONTRIBUTING.md](docs/CONTRIBUTING.md)。
